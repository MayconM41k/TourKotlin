# TourKotlin

Repositório de exercícios práticos em Kotlin, organizado por níveis de dificuldade para ajudar no aprendizado da linguagem de forma gradual e estruturada.

## Objetivo

Este projeto foi criado para praticar os fundamentos e conceitos intermediários de Kotlin por meio de exercícios progressivos, com foco em:

- sintaxe da linguagem
- variáveis e tipos
- condicionais e laços
- funções
- coleções
- programação orientada a objetos
- lógica e resolução de problemas

## Níveis

### Novato

Direcionado para quem está começando em Kotlin. Os exercícios cobrem conceitos básicos e fundamentais.

### Intermediario

Voltado para quem já conhece a linguagem e deseja aprofundar lógica, estruturas e práticas mais avançadas.

## Como usar

1. Clone este repositório.
2. Abra os exercícios em uma IDE ou editor com suporte ao Kotlin.
3. Resolva cada tarefa em ordem.
4. Teste e execute os arquivos `.kts`.
5. Revise seu código e pratique a lógica repetidamente.

## Requisitos

- Java JDK instalado
- Kotlin configurado no ambiente
- IDE ou editor como IntelliJ IDEA, VS Code ou outra ferramenta compatível

## Dicas de estudo

- resolva os exercícios na sequência
- tente entender a lógica antes de buscar a solução
- refatore os códigos quando possível
- pratique com pequenas variações dos mesmos exercícios
